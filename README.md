# SignalSync

SignalSync is a FiveM resource that allows players to set keybinds for their vehicle's turn signals. It provides a simple and intuitive way to control turn signals using keyboard inputs or on-screen buttons, enhancing the driving experience in FiveM.

## Install

1. Download the SignalSync resource from the GitHub repository.
2. Extract the downloaded file into your FiveM resources directory.
3. Add the following line to your `server.cfg` file to ensure the resource starts with your server:
   ```
   ensure SignalSync
   ```

## Use

1. Start your FiveM server with the SignalSync resource enabled.
2. Join a game session and enter a vehicle.
3. Use the following keybinds to control the turn signals:
   - Left Arrow Key: Toggle left turn signal
   - Right Arrow Key: Toggle right turn signal
4. Alternatively, you can use the on-screen buttons to toggle the turn signals.
